# Audio Sources

The first audio catalog intentionally uses only the three placeholder WAV files
already shipped with Ember Camp:

- `assets/audio/music/placeholder.wav` - temporary music placeholder.
- `assets/audio/ambience/placeholder.wav` - temporary ambience placeholder.
- `assets/audio/sfx/placeholder.wav` - temporary sound-effect placeholder.

These files are project placeholders, not third-party source material. No new
audio assets were added in Task 1. Future replacements must record the source
URL, license, attribution requirement, and redistribution permission here.
