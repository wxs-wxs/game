# Audio Sources

The runtime audio shipped in this branch is limited to the existing placeholder
WAV files already in the project:

- `assets/audio/music/placeholder.wav` - temporary music placeholder.
- `assets/audio/ambience/placeholder.wav` - temporary ambience placeholder.
- `assets/audio/sfx/placeholder.wav` - temporary sound-effect placeholder.

These are project-owned placeholders, not third-party runtime assets. No new
audio downloads were added for the audio service work. Any future replacement
must record the source URL, license, attribution requirement, and redistribution
permission here before it is imported.
